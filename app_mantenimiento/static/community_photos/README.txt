Community photos
================

Drop a photo here for each community to replace the gradient placeholder on the
dashboard cards. If no photo is found, the card automatically falls back to the
gradient + building icon — so this is optional and safe to leave empty.

NAMING
------
Name each file using the community's lowercase name with every run of
non-letter/number characters replaced by a single underscore, ending in ".jpg".

Examples:
  "Kelley Place, Enterprise"              ->  kelley_place_enterprise.jpg
  "The Goldton at Athens"                 ->  the_goldton_at_athens.jpg
  "Madison at The Range, Madison"         ->  madison_at_the_range_madison.jpg
  "Legacy Ridge at Buckhead, Atlanta"     ->  legacy_ridge_at_buckhead_atlanta.jpg

TIPS
----
- Use .jpg files (landscape works best; the card crops to a 200px-tall area).
- Keep them reasonably sized (e.g. ~1200px wide) so the dashboard stays fast.
- After adding/replacing a photo, hard-refresh the dashboard (Cmd+Shift+R).
